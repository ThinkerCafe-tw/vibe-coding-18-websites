# 用 AI 助手 跟著課程操作

## 1. 先準備一個專案資料夾

在 AI 助手 桌面應用中開啟該集資料夾。EP01 的資料夾是 `episodes/ep01-cafe`。

開始前，先請 AI 助手讀取：

- `README.md`
- `PROMPT-CARD.md`
- `SPEC.md`
- `VERIFY.md`

## 2. 用說的，不必背稿

使用錄音輸入或直接打字，像開會一樣描述需求。先請 AI 助手 回述，不要第一句就要求它施工。

```text
先不要修改檔案。請回述你聽懂的目標、使用者、必要內容，以及還需要我確認的資料。
```

## 3. 看懂規格再批准

確認 AI 沒有誤解，也沒有自行編造資料後，再請它把共識整理成規格。只有在規格可接受時，才明確說「可以施工」。

## 4. 實際打開網站

不要只看文字回報。請 AI 助手 用瀏覽器打開網站，也在自己的手機或窄視窗檢查：

- 文字是否超出畫面
- 圖片是否正常
- 電話與導航是否送出正確資料
- 手機修正是否破壞桌機版

## 5. 用截圖指出問題

看到問題時附上截圖，說明「我在哪個畫面看到什麼」。你不必先猜是哪一行程式造成的，也不必自己提供精確像素。

```text
這張手機截圖裡，右側內容超出畫面。請先量測並解釋原因，提出最小修正方案，先不要修改。
```

方案合理後再批准修正，並要求重做同一組驗收。
