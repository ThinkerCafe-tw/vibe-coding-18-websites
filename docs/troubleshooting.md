# 常見問題

## 網站打不開

先確認解壓縮後的資料夾結構完整，並打開該集 `site/index.html`。若首頁的課程搜尋無法使用，請改用公開學員網站；搜尋功能需要透過網站伺服器載入課程索引。

## 圖片沒有顯示

不要只複製 `index.html`。請保留解壓後的完整套件，尤其是整個 `site` 資料夾與原有相對位置。圖片資料夾依講次不同：EP01 使用 `site/assets`，EP02–15 使用 `site/images`；EP16–18 沒有另外附站內照片資料夾。以各講實際檔案為準，不要自行把 `images` 改名為 `assets`。

## AI 一開始就改了檔案

先停止這一輪，重新說明：

```text
先不要修改檔案。請回述需求、列出缺漏，等我批准規格後才能施工。
```

## AI 給了很多精確尺寸，我看不懂

請它改用你能判斷的語言，並把量測留給它：

```text
請先用一般使用者看得懂的方式說明畫面出了什麼問題。技術量測可以保留在附註，不要把它寫成我要照念的話。
```

## AI 說完成，但畫面還是有問題

把實際畫面截圖交給 AI，說明裝置或視窗寬度，要求它先分析再提出最小修正。修正後，重新做手機與桌機驗收，不沿用上一輪的成功結論。

## 可以把範例直接改成正式網站嗎

可以作為起點，但所有示意文字、圖片、電話、地址、價格、隱私與服務流程都必須重新確認。涉及預約、付款、醫療、法律或會員資料時，還需要符合實際業務與法規，不能把課程示意當成正式系統。
