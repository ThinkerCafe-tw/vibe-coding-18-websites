# EP01 山風咖啡

第一集不是從背一大段提示詞開始，而是從一段自然對話開始。你會把「我想做什麼」說清楚，請 AI 回述、補問、整理成規格，批准後才施工，最後親自驗收網站。

## 這一集會完成

1. 用自然對話說出網站需求。
2. 請 AI 回述理解與缺漏，不急著寫程式。
3. 把確認過的內容整理成施工規格。
4. 批准施工後，檢查手機與桌機版。
5. 用截圖指出問題，再做最小幅度修正。

## 直接開始

- [開啟完成版網站](site/)
- [先看施工規格](SPEC.md)
- [跟著對話卡操作](PROMPT-CARD.md)
