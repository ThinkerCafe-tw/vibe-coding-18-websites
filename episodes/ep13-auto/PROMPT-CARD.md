# EP13 對話提示卡

以下為第 13 講第 5.1 節既有提示詞。請先核對需求與資料，再用自己的話與 AI 確認；示意資料不要當成真實商家資料。

## 教材提示詞

```text
你是網頁設計老師與前端工程師。
請幫我做成一個可以直接打開的「汽車保養網站」單頁原型。

【網站目標】
服務項目、預約、車籍資料、里程提醒與透明報價

【使用者情境】
使用者第一次進入網站時，需要在手機上快速判斷這個服務是否適合自己，並能完成主要行動：查詢服務項目、預約保養、記錄車籍與下次回廠提醒。

【必要區塊】
1. Hero 首頁：名稱、定位、主張、主要行動按鈕
2. 信任證據：真實照片、資歷、評論、規則或案例
3. 服務項目與透明報價：保養項目、參考價格，並示範一張把「零件」與「工資」分欄、每列帶車主同意狀態的估價單
4. 預約與車籍：預約保養的表單，以及記錄車牌、車型、目前里程的車籍區塊
5. 保養紀錄與下次提醒：列出完成項目與里程，並依里程門檻或時間間隔顯示「下次回廠提醒」文案
6. 聯絡與後續：電話、LINE、Email、地圖或確認訊息

【資料欄位】
請在頁面中示範下列資料結構（對應表 13-3）：
1. VehicleProfile：車牌、品牌、車型、年份、目前里程
2. CustomerProfile：車主姓名、電話、Email、聯絡偏好
3. ServiceMenu：保養項目、參考價格、所需時間、適用車型
4. Appointment：日期、時段、車輛、服務項目、狀態
5. WorkOrder：檢查項目、建議維修、車主同意狀態、完工狀態
6. EstimateLine：零件、工資、數量、單價、是否同意
7. MaintenanceRecord：日期、里程、完成項目、照片、下次建議
8. ReminderRule：里程門檻、時間間隔、提醒內容

【設計要求】
1. 請用清楚的 HTML結構與 CSS，建成一個可以直接打開的單一 index.html，CSS 寫在同一個檔案裡。
2. 請使用 RWD，手機、平板、桌機都要可讀。
3. 請避免假評價、假資歷、假價格或過度承諾。
4. 表單與按鈕要有清楚的互動狀態，可以用靜態示意，不需要真的送出到伺服器。
5. 請在每個區塊用佔位文字標註上線前要替換的真實內容，不要編造店家資歷、價格與評論。
```


## 實作時補上的一致性條件

- 里程必須是 0 至 9999999 的整數公里數。保養提醒不可把負號、小數點或文字刪掉後當成有效數值；錯誤顯示在里程欄位。
- 預約里程可留白；有填則送出前重新驗證格式，通過才建立預約。0 公里與空白分開處理。


## 本頁資料與操作一致性

- 同一頁連續送出多筆時，每筆使用不同編號，先前資料保留在「本頁紀錄」，點編號可展開查閱。名額仍依各自預約計算，不因下一筆摘要出現而遺失。重新整理會清空本頁新增紀錄並還原示例。


## 必填文字驗證

- 車主姓名、電話、車牌等必填文字送出前去除首尾空白；空字串或只有空白時保留表單並提示，不建立紀錄、不占名額。內容中間的正常空格應保留。共用驗證程式隨本講 ZIP 提供，直接開檔也要生效。

- 沿用本公開套件時，請保留 ZIP 內的共用驗證程式與相對路徑，解壓後可直接開啟 index.html。

## 表單確認與新草稿

- 成功送出後，只要修改輸入、切換選項、重設表單或再次送出未通過驗證，立即撤回上一筆成功提示。
- 只撤回表單確認，不刪除原本已有編號的本頁紀錄，也不重複扣除名額；使用者可從本頁紀錄查閱先前資料。
- 程式內部在成功後清空表單時，先完成清空再顯示這一次確認；使用者開始填寫下一筆時才撤回。

## 保養紀錄、提醒與防重

- 查詢結果與提醒綁定同一車牌、同一筆最後完成的保養紀錄。ABC-1234 的基準是 2026/04/09、52,000 公里；依 5,000 公里或 6 個月計算，建議 57,000 公里或 2026/10/09，先到者。
- 僅送出預約，不新增已完成保養紀錄，不重設保養週期；預約確認採用該車相同的紀錄來源，不使用本次填入里程加 5,000。
- 查無車牌時，查詢區與預約確認均說明無法依歷史推算，清除上一輛車的提醒、進度與日期；重新查已知車牌才恢復該車提醒。
- 同頁同時段同車牌重訂應攔阻第二筆，紀錄與名額不變；跨瀏覽器與同時請求的防重另由正式後端實作。

## 示範時段與里程一致性

- 時段表稱為「示範時段」，明示固定教學基準日 2026/10/09 與日期範圍 2026/10/09–10/14。
- 提醒與預約共用同車最後完成保養紀錄。填入的目前里程不得低於該紀錄；ABC-1234 下界為 52,000 公里。倒退值先核對車牌與里程；曾更換儀表須聯絡店家核實，本示例不提供直接跳過核對的流程。
- 切換車牌、輸入里程及送出時均重新檢查。無效時不新增預約、不扣名額、不計算誤導的剩餘公里數。未知車牌不借用其他車的紀錄；預約里程仍可留空，有填須符合整數格式。
