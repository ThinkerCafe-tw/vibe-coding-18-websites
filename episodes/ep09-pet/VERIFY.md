# EP09 驗收清單

## 逐項檢查

AI 產出後，不要只看第一眼漂不漂亮，請依序檢查：

- [ ] 首頁第一屏是否說清楚服務適合誰、下一步是什麼。
- [ ] 是否收集寵物品種、年齡、體重、健康與行為備註，而不是只留姓名電話。
- [ ] 是否有服務前後照片紀錄，而不是只放漂亮成品照。
- [ ] 是否清楚說明風險同意、緊急聯絡、建議就醫情境。
- [ ] 是否避免把健康異常包裝成強迫加購，且價格、限制、取消、隱私規則清楚。
- [ ] 手機版是否能完成主要行動，且文字按鈕不重疊。

`HealthNote` 是飼主自由打字的欄位，等於把外人輸入的內容收進系統，所以收到的最少資料也要安全：顯示前先逸出、查詢用參數化——見第 17 講。

## 主動測試

這一講裡飼主會填表、會佔一個時段，預約還會在狀態之間流轉，最危險的錯藏在畫面上看不出的地方。最招牌的一招，是同一位美容師、同一個時段連訂兩次，看第二次擋不擋、名額會不會變成負的。

記住：**AI 是被告不是法官，畫面才是證據**，它嘴上說「狀態都鎖好了」不算數。


## 資料一致性主動回驗

- [ ] 選貓咪洗澡烘乾，只列 10/6 吳美容師時段；不能用 10/3 林美容師的一般洗澡時段取名額。
- [ ] 依序輸入「不是數字」、-5、0、100.01、8.123；每次都應顯示體重錯誤，且原名額不變。輸入 8.25 才可建立預約並扣一名。


## 多筆資料與操作一致性回驗

- [ ] 以不同飼主、電話與寵物資料，分別選有名額且服務相容的時段送出；核對 PET 編號不同，展開第一筆比對飼主、聯絡電話、寵物、年齡體重、服務項目、時段、緊急聯絡與風險同意。

- [ ] 逐張對照目前照片與 alt；主體、動作與場景一致，換圖時同步修正替代文字與下載套件。

## 必填文字邊界回驗

- [ ] 逐一把飼主姓名、電話、寵物名字、品種、年齡、體重、緊急聯絡人及電話填成三個半形空格（其餘必填合法）再送出，應保留表單並指出錯誤，紀錄與名額不變；全形空格與空字串也要攔阻。
- [ ] 改成正常資料後可送出一次。姓名使用「  測試 王  」時，保存或摘要應為「測試 王」，保留中間空格；其他欄位須符合各自格式。

## 成功後再次編輯回驗

- [ ] 先用合法資料送出並看到確認，再修改姓名或聯絡欄位，上一筆成功提示應立即消失。
- [ ] 逐一測試半形空格、全形空格、空字串、撤回必要同意與重設表單；未通過時不能留下成功提示，既有編號、紀錄內容與名額不得因此改變。
- [ ] 若有日期、時段、班級或模式按鈕，改選也應撤回舊確認。修正資料後可建立新的確認；原本已有編號的本頁紀錄仍可查閱。

## 緊急電話與年齡驗證回驗

- [ ] 緊急電話 abcde 擋下且名額與紀錄不變；合法手機、市話可送出。
- [ ] -5歲、abc、1.5歲、3歲12個月 擋下；0歲3個月、3歲6個月、3個月與整數歲合法，不誤擋幼齡。
