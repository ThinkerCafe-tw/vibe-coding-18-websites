## 在自己的電腦開啟

解壓縮後直接開啟 `site/index.html`；也可在課程根目錄執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000`。

這是課程示意原型。預約、付款、會員、通知等互動以本機模擬示範；教材裡的正式後端責任另列為延伸驗收。請使用虛構練習資料。
