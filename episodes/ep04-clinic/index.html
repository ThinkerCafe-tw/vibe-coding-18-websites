EP04 施工規格

本規格整理自《網頁設計》第 4 講第 5.1 節的需求；是學員審閱與實作依據。

網站目標

單頁診所網站，包含醫師簡介、診次表、預約時段選擇、額滿狀態、衛教資訊與交通方式。

使用者情境

使用者第一次進入網站時，需要在手機上快速判斷這個服務是否適合自己，並能完成主要行動：查看診次、預約時段、理解候診與用藥說明。

必要區塊

  1. Hero 首頁：診所名稱、科別、醫師主張、預約按鈕
  2. 醫師簡介：學經歷、專長、看診理念
  3. 診次表：一般門診、特殊診別、休診日
  4. 預約時段：日期、時段、名額上限、額滿狀態
  5. 衛教資訊：常見症狀、用藥提醒、複診說明
  6. 交通與候診：地址、停車、即時號碼示意

資料欄位

請在頁面中示範下列資料結構：

  1. ClinicProfile：診所名稱、科別、地址、電話
  2. Doctor：姓名、專長、學經歷、理念
  3. SessionType：診次名稱、星期、開始時間、結束時間、名額上限
  4. AppointmentSlot：日期、時段、已預約人數、狀態
  5. PatientRequest：姓名、聯絡方式、症狀備註、是否慢箋
  6. ReminderPreference：簡訊提醒、複診提醒、取消規則

設計要求

  1. 請用清楚的 HTML結構與 CSS，幫我做成一個可以直接打開的單一入口 index.html，CSS 就寫在同一個檔案裡。
  2. 請使用 RWD，手機、平板、桌機都要可讀。
  3. 請避免假評價、假資歷、假價格或過度承諾。
  4. 表單與按鈕要有清楚的互動狀態，可以用靜態示意，不需要真的送出到伺服器。
  5. 請在容易被誤讀成醫療建議的文字旁加註「本網站僅供預約與資訊參考，不取代醫師當面診斷」。

本練習包的素材

照片用於診所首頁主視覺與診療空間介紹。練習重點是看診時段、剩餘名額與預約確認；更換照片時保留資訊可讀性，不以照片暗示未經核實的醫療資格或療效。來源說明見 ATTRIBUTION.md。

資料一致性規則

  • 科別與診次使用同一份關聯資料；診次保留醫師及科別。變更科別後清空診次，選單只列該科仍有名額的診次。
  • 送出前再次核對診次、科別與醫師；不符時在時段欄位顯示錯誤，不能建立預約或扣名額。

本頁資料與操作一致性

  • 同一頁連續送出多筆時，每筆使用不同編號，先前資料保留在「本頁紀錄」，點編號可展開查閱。名額仍依各自預約計算，不因下一筆摘要出現而遺失。重新整理會清空本頁新增紀錄並還原示例。
  • 「回到初始狀態」或重設示例會一併清除本頁紀錄並還原名額；不能只清摘要而保留占位。

必填文字驗證

  • 姓名、電話等必填文字送出前去除首尾空白；空字串或只有空白時保留表單並提示，不建立紀錄、不占名額。內容中間的正常空格應保留。共用驗證程式隨本講 ZIP 提供，直接開檔也要生效。

表單確認與新草稿

  • 成功送出後，只要修改輸入、切換選項、重設表單或再次送出未通過驗證，立即撤回上一筆成功提示。
  • 只撤回表單確認，不刪除原本已有編號的本頁紀錄，也不重複扣除名額；使用者可從本頁紀錄查閱先前資料。
  • 程式內部在成功後清空表單時，先完成清空再顯示這一次確認；使用者開始填寫下一筆時才撤回。

固定示範診次

  • 頁首與名額板稱為「示範診次」，固定教學基準日 2026/06/01。2026/06/01–03 的診次、看診號碼與名額供流程練習，不宣稱是讀者今日的即時診次。

診次提示與名額

  • 上一筆送出後改選空白時，提示依該診次目前狀態顯示。仍可預約時可重新選擇；只有額滿或停診才顯示不再開放。

EP04 驗收清單

逐項檢查

AI 產出後，不要只看第一眼漂不漂亮——版面不拘，下列各項齊全就算合格初版。請依序檢查：

  • [ ] 每個時段是否有名額上限；額滿時是否改為「額滿」或「候補」，不能再點選。
  • [ ] 診次是否能區分可預約、接近額滿、額滿、停診與已結束 — 停診和額滿原因不同，要分開呈現。
  • [ ] 是否保留現場掛號或候診資訊，避免網站承諾超過實際現場容量。
  • [ ] 複診提醒是否有明確同意文字，且沒有混入行銷授權。
  • [ ] 醫療文案是否避免療效保證與恐嚇式語言，手機上是否能快速找到電話、地址與預約入口。

主動測試

這一講裡病患會填表、而且填完會卡住（名額、額滿、候補），最容易出「看起來能約、其實後端沒擋」的沉默失敗。最招牌的一撞：選一個「可預約」時段送出，再回去選同一時段再送一次，看第二次擋不擋——前端示意常常照收，這就是超賣的破口。

AI 是被告不是法官，畫面才是證據。 問寫網站的 AI「額滿會擋住嗎？」它幾乎一定回「會」，但真相只能你自己送兩次、看第二次擋沒擋。

資料一致性主動回驗

  • [ ] 選耳鼻喉科，不能選到家醫科王醫師診次；切到家醫科選下午診，再切回耳鼻喉科，已選診次應清空。
  • [ ] 以錯誤科別／診次組合送出，時段欄位出錯且名額不變；家醫科與王醫師的有效預約仍可用掉最後一名。

多筆資料與操作一致性回驗

  • [ ] 使用不同姓名與電話，分別選有餘額的相容科別／診次送出兩筆；核對 CL 編號不同，展開第一筆比對姓名、電話、科別、醫師、診次、症狀備註與提醒同意，資料仍與第一筆輸入一致。

必填文字邊界回驗

  • [ ] 逐一把姓名、電話填成三個半形空格（其餘必填合法）再送出，應保留表單並指出錯誤，紀錄與名額不變；全形空格與空字串也要攔阻。
  • [ ] 改成正常資料後可送出一次。姓名使用「 測試 王 」時，保存或摘要應為「測試 王」，保留中間空格；其他欄位須符合各自格式。

成功後再次編輯回驗

  • [ ] 先用合法資料送出並看到確認，再修改姓名或聯絡欄位，上一筆成功提示應立即消失。
  • [ ] 逐一測試半形空格、全形空格、空字串、撤回必要同意與重設表單；未通過時不能留下成功提示，既有編號、紀錄內容與名額不得因此改變。
  • [ ] 若有日期、時段、班級或模式按鈕，改選也應撤回舊確認。修正資料後可建立新的確認；原本已有編號的本頁紀錄仍可查閱。

固定示範診次回驗

  • [ ] 在不同真實日期開頁，應能看見固定教學基準日 2026/06/01；原示範名額與科別、醫師、診次驗證仍可練習。

診次提示與名額回驗
