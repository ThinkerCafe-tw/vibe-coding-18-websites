# EP02 驗收清單

## 逐項檢查

AI 產出後不要只看第一眼漂不漂亮，請依序檢查。第一版提示詞只要求表 2-2 的基本欄位，下列幾項（如私教課包堂數、會籍冷靜期）第一版可能還沒有——這不是做錯，而是要請 AI 補強的下一步：

- [ ] 首頁第一屏是否說清楚場館適合誰，而非只放肌肉照。
- [ ] 教練證照、價格、退費規則是否為真實資料。
- [ ] 體驗預約是否有日期、時段、教練與確認狀態。
- [ ] 私教課包是否有堂數、有效期限、剩餘堂數與退費規則。
- [ ] 會籍暫停、轉讓、終止與冷靜期是否清楚。
- [ ] 補充品或體態成果是否避免保證式、恐嚇式文案。
- [ ] 首次體驗流程是否讓新手知道進門後會發生什麼。
- [ ] 手機版按鈕是否好點，預約入口是否清楚。

## 主動測試

本講的網站是「會請客人填東西」的體驗預約表單站（會收一張表，但不會真的鎖場次、不扣錢）。最招牌的一測：什麼都不填就按「預約首次體驗」，看它擋不擋、有沒有提示哪格必填。

**AI 是被告不是法官，畫面才是證據**——它說表單沒問題不算數，親手送一次、回頁面看反應才算數。

## 必填文字邊界回驗

- [ ] 逐一把姓名、聯絡方式、想改善的目標填成三個半形空格（其餘必填合法）再送出，應保留表單並指出錯誤，紀錄與名額不變；全形空格與空字串也要攔阻。
- [ ] 改成正常資料後可送出一次。姓名使用「  測試 王  」時，保存或摘要應為「測試 王」，保留中間空格；其他欄位須符合各自格式。
