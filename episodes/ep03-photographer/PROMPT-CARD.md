# EP03 對話卡

這張卡的重點不是背指令，而是把「畫面完成」一路推進到「公開網址可重做驗收」。

## 1. 先交代目標與素材

> 我想做一個攝影師作品集。請先核對我提供的服務、方案、圖片和授權，不要補寫獎項、評價、品牌或客戶姓名。先整理成可批准的規格，不要施工。

## 2. 批准後完成本機作品

> 規格已確認，可以開始。請做手機優先的網站，第一屏要說清楚服務與自然、不過度修飾的風格，接著呈現作品、方案、關於與詢問入口。

## 3. 要求可重做的驗收

> 請分別檢查桌機、一般手機與最窄手機；實際測試表單必填、13 張圖片路徑與 SEO。不要只告訴我程式看起來正確。

## 4. 保存與發布

> 本機驗收通過後，建立內容清楚的版本並推到公開 repo 的 main。等待已連結的 Vercel 完成部署，再開啟固定 production URL 驗收。

## 5. 最後只看四個停點

> 請用白話回報：作品已整理、手機已檢查、版本已保存、公開網址可驗收；每個停點都要有實際證據支持。
