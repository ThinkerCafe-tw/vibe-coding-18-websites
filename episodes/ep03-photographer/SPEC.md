# EP03 施工規格

本規格整理自《網頁設計》第 3 講第 5.1 節的需求；是學員審閱與實作依據。

## 攝影師資料

名稱：小柯攝影工作室
地區：台中
服務類型：婚紗、婚禮紀錄、形象照
品牌主張：自然、不過度修飾，重視情緒與現場關係
主要客群：準新人、小型品牌主、需要形象照的專業工作者

## 網站目標

1. 讓第一次來的客人快速看懂攝影風格
2. 讓作品依照類型清楚分類
3. 說明拍攝流程、方案內容、交件時間與加選規則
4. 引導客人填寫詢問表單
5. 讓網站可部署為單頁靜態網站（靜態網站＝內容固定、伺服器原樣送出的網頁，不需後端程式即時運算，最省事也最好部署）

## 必要區塊

1. 首頁主視覺：攝影師名稱、服務類型、一句話主張、兩個按鈕「看作品」「詢問檔期」
2. 作品分類：婚紗、婚禮紀錄、形象照，每類 4 到 8 張示意圖（placeholder）
3. 案例說明：每一類用 2 到 3 句說明拍攝情境
4. 服務方案：方案名稱、內容、價格區間、交件時間、加選規則
5. 拍攝流程：詢問、溝通、拍攝、精修、交件
6. 關於我：攝影師介紹與工作方式
7. 詢問表單：姓名、聯絡方式、拍攝類型、日期、地點、預算、留言
8. 頁尾：Email、Instagram、服務地區、版權聲明

## 視覺風格

照片優先、留白、專業、安靜、不要過度裝飾。
背景可以用白色、深灰或低飽和米色。
按鈕要清楚，但不要太花。

## 技術要求

1. 請做成一個可以直接打開的單一 index.html 檔案。
2. CSS 寫在同一個檔案內。
3. 使用語意化 HTML，例如 header、main、section、footer。
4. 圖片先用免費圖庫（如 Unsplash）的示意圖，並用註解標出日後要替換的圖片檔名。
5. 每張圖片都要有 alt 文字。
6. 使用響應式設計，桌機作品集可三欄，手機改為單欄。
7. 文字在手機上至少要容易閱讀，按鈕要容易點。
8. 表單不需要真的送出到後端，但要有清楚欄位與送出按鈕。
9. 不要編造得獎紀錄、客戶評價或合作品牌。
10. 請在 HTML title 與 meta description 放入適合 SEO 的文字。


## 本練習包的素材

照片版位使用原創 SVG 示意圖，保留分類、燈箱與版面操作；實際照片由學員另備合法素材。來源記錄見 `ATTRIBUTION.md`。
