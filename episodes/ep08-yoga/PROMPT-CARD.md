# EP08 對話提示卡

以下為第 8 講第 5.1 節既有提示詞。請先核對需求與資料，再用自己的話與 AI 確認；示意資料不要當成真實商家資料。

## 教材提示詞

```text
你是網頁設計老師與前端工程師。
幫我建一個「瑜伽教室課程報名網站」單頁原型。

【網站目標】
讓學員能查看老師、課程類型、週課表、剩餘名額，並完成體驗課報名或候補登記。

【必要區塊】
1. 首頁：教室名稱、主張、體驗課按鈕
2. 老師介紹：老師姓名、證照、專長、教學風格
3. 課程類型：課名、難度、適合對象、注意事項
4. 週課表：星期、時間、老師、教室、名額、狀態
5. 報名表單：姓名、電話、課程、身體狀況、經驗程度
6. 候補說明：候補順位、通知方式、保留回覆時間
7. 取消規則：取消期限、未到處理、扣堂規則

【資料模型】
請示範 Teacher、ClassType、ClassSession、Enrollment、WaitlistEntry、StudentNote。

【互動示意】
用少量 JavaScript示範：課程剩餘名額為 0 時，按鈕改成「加入候補」；送出候補後顯示候補順位；選擇不同課程時顯示不同老師與難度。

【設計要求】
做成一個可以直接打開的單一 index.html（HyperText Markup Language，超文字標記語言）檔案，CSS寫在同一個檔案內，使用 RWD，手機上課表要能清楚閱讀。文案要避免神化老師、誇大療效或承諾治癒。
```


## 本頁資料與操作一致性

- 同一頁連續送出多筆時，每筆使用不同編號，先前資料保留在「本頁紀錄」，點編號可展開查閱。名額仍依各自預約計算，不因下一筆摘要出現而遺失。重新整理會清空本頁新增紀錄並還原示例。
- 「回到初始狀態」或重設示例會一併清除本頁紀錄並還原名額；不能只清摘要而保留占位。


## 必填文字驗證

- 姓名、電話等必填文字送出前去除首尾空白；空字串或只有空白時保留表單並提示，不建立紀錄、不占名額。內容中間的正常空格應保留。共用驗證程式隨本講 ZIP 提供，直接開檔也要生效。

- 沿用本公開套件時，請保留 ZIP 內的共用驗證程式與相對路徑，解壓後可直接開啟 index.html。
